github-final-project
A small shell script that calculates simple interest from the principal amount, the rate of interest, and the time period.

Usage
Make the script executable: chmod +x simple-interest.sh
Run it: ./simple-interest.sh
Enter the principal, the rate (in %), and the time (in years) when prompted.
Formula
Simple Interest = (Principal x Rate x Time) / 100
