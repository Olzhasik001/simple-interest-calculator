# github-final-project

A small shell script that calculates simple interest from the principal amount, the rate of interest, and the time period.

## Usage

1. Make the script executable: 
   ```bash
   chmod +x simple-interest.sh
   ```
2. Run it: 
   ```bash
   ./simple-interest.sh
   ```
3. Enter the principal, the rate (in %), and the time (in years) when prompted.

## Formula

$Simple\ Interest = \frac{Principal \times Rate \times Time}{100}$
